# Fleetra - Robot Simulation Packages

This directory contains the ROS 2 packages and 3D simulation assets for the autonomous mobile robots (AMRs) used in the Fleetra warehouse orchestration system:

- **amazon_robot_bringup**: Launch files, world configurations, maps, and gazebo entity spawner.
- **amazon_robot_controller**: Action clients and motion controllers for robot waypoint following and lift mechanism activation.
- **amazon_robot_description**: URDF, Xacro definitions, meshes, and kinematics configurations.
- **amazon_robot_gazebo**: Gazebo plugin integrations, sensor models, and simulation worlds.
- **amazon_robot_msg**: Custom ROS 2 message and action definitions (`FollowTargets`).
- **amazon_robot_rviz_plugins**: RViz visualization panels and interaction tools.
- **aws-robomaker-small-warehouse-world**: High-fidelity AWS RoboMaker small warehouse world model and assets.
- **exercise**: Multi-agent task planning and job sequencer (`multi-robot.py`).
